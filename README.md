# 🚀 Portfólio Profissional — Emerson Campos

Portfólio desenvolvido com foco em performance, responsividade e experiência do usuário, apresentando meus projetos, habilidades e informações profissionais como Desenvolvedor Front-End.

O site foi construído utilizando HTML, CSS e JavaScript puro, com identidade visual moderna inspirada em interfaces minimalistas e cyberpunk, utilizando tons escuros e detalhes em verde neon.

🔗 Acesse o site: Clique aqui https://emerson-o-campos.github.io/portifolio/

## ✨ Funcionalidades

* Layout moderno e totalmente responsivo
* Animações suaves e interativas
* Cursor customizado neon
* Cards de projetos com hover effects
* Scroll suave entre seções
* Design focado em UI/UX
* Download de currículo
* Links diretos para GitHub, LinkedIn e WhatsApp

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts (Inter)

## 📂 Projetos em Destaque

* 🐾 Pet Love Care
* ⚡ Eletubos
* 📢 JRC Divulgação

## 🎯 Objetivo

Este projeto foi criado com o objetivo de apresentar minhas habilidades como desenvolvedor Front-End, demonstrar evolução técnica e servir como vitrine profissional para oportunidades de estágio, freelas e futuras colaborações.
